Design Feature — How to Use
Nova AI Image Generator — Step by Step Guide
1
📁 VS Code හදා ගන්න
VS Code open කරලා, File → Open Folder click කරලා, ඔයාගේ project folder එකක් select කරන්න (හෝ Desktop ෙ new folder එකක් හදාගන්න).
2
📄 index.js File හදන්න
VS Code ෙ left sidebar ෙ Explorer panel ෙ "New File" icon click කරලා:
index.js
කියලා name දෙන්න. Enter press කරන්න.
3
📋 Code Copy කරලා Paste කරන්න
Nova දෙන code ෙ top-right corner ෙ Copy button click කරන්න. ඊළඟට index.js file ෙ ඇතුළෙ click කරලා Ctrl+V press කරන්න.
4
💾 Save කරන්න
File save කරන්න:
Ctrl + S
5
⚡ Terminal ෙ Run කරන්න
VS Code ෙ Terminal menu → New Terminal click කරන්න. Terminal ෙ type කරන්න:
node index.js
Enter press කරන්න. Output ෙ result display වේවි! 🚀
